# Mystery Island: The Lost Lighthouse 

## About the Game

Mystery Island is a simple adventure game I built with Python.

In this game, the player explores an island, collects items, and tries to find the lost lighthouse.
You need to collect a rope to cross the bridge and a lantern to enter the lighthouse.

Be careful with your energy because you can lose the game if it runs out!

## What the Game Can Do

- Ask the player for their name.
- Let the player explore five different locations.
- Allow the player to collect a rope and a lantern.
- Track the player's energy and inventory.
- Stop the player from crossing the bridge without a rope.
- Stop the player from entering the lighthouse without a lantern.
- Allow the player to check their status and inventory.
- Show a win or game-over message.
- Allow the player to play again.

## Locations

- **Beach:** Where the adventure begins.
- **Forest:** Where you find the rope.
- **River:** Where you cross the bridge.
- **Cave:** Where you find the lantern.
- **Lighthouse:** Your final destination.

## What You Need

- Python installed on your computer.
- A code editor, such as VS Code.
- A terminal to run the game.

No extra Python packages are needed.

## How to Run the Game

Open your terminal and move into the project folder.

On Windows, run:

```bash
py main.py
```

On Linux or macOS, run:

```bash
python3 main.py
```

## How to Play

Start the game and enter your name. Use the numbered menu to choose what you want to do.

Explore the island, collect the items you need, and manage your energy carefully. Your goal is to reach the lighthouse and win the game.
